# Student Management System

A beginner-friendly Student Management System built with Python. This project demonstrates Object-Oriented Programming (OOP), input validation, and JSON file handling.

## Features

- Add student records
- Display all students
- Search for a student by roll number
- Calculate average marks
- Validate user input and prevent duplicate roll numbers
- Save and load student records using JSON
- Interactive command-line menu

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- Git and GitHub

## Requirements

- Python 3 installed on your computer

No external Python packages are required.

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   py main.py
   ```

The program will display a menu that lets you manage student records.

## Data Storage

Student records are stored in `students.json`. The program loads existing records when it starts and saves new records when students are added.

If the JSON file does not exist, the program starts with an empty student list.

## Learning Objectives

This project was created to practise Python classes and objects, methods, input validation, JSON persistence, Git version control, and publishing code on GitHub.
